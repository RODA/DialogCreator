IN PRACTICE / DIALOGR

A dialog selection.
A corresponding R command.

DialogR brings this workflow to statistical analysis. Its Frequency table dialog lets a researcher choose a dataset and a variable, then inspect the R command before running it.

For example, selecting B1_polintr from ess builds a frequency-table command. Choosing to include the variable label adds vlabel = TRUE. JavaScript captures that intent; DialogR runs the resulting R code.

THE RESEARCHER’S INTENT

“Show the frequency table for political interest, including its variable label.”

THE GENERATED R COMMAND
using(
  ess,
  wtable(B1_polintr, vlabel = TRUE)
)

An example from DialogR’s frequency-table actions. The command stays visible and can be inspected.
